## Membuat token
1. Masuk GitHub sebagai dlom2.
2. Buka https://github.com/settings/personal-access-tokens/new
3. Token name: MQA Galeri Santri. Expiration: 90 hari atau sesuai kebutuhan; perbarui sebelum habis.
4. Resource owner: dlom2.
5. Repository access: Only select repositories, pilih geleri.
6. Repository permissions: Contents — Read and write, agar fitur upload, rename, dan delete dapat bekerja. Metadata — Read-only. Jika hanya membaca foto, Contents — Read-only cukup.
7. Generate token; salin token dan simpan sebagai rahasia. Jangan tempel ke chat, JavaScript, atau repo.
## Memasang token pada hosting
Di File Manager InfinityFree, buka /htdocs/private/runtime_config.php.
Cari bagian github. Ubah hanya nilai terkait:
```php
'github' => [
    'token' => 'ISI_TOKEN_BARU_DI_HOSTING',
    'user'  => 'dlom2',
    'repo'  => 'geleri',
    'path'  => 'assets/img',
],
```
Ini contoh bagian konfigurasi, bukan pengganti seluruh file. Pertahankan bagian database, integrasi lain, dan key tambahan yang sudah ada.
Simpan, lalu buka halaman foto santri dengan akun admin dan muat ulang.
Pastikan daftar foto tampil; saat diperlukan, uji unggah satu foto santri yang memang ingin diperbarui.
Token lama tidak memperoleh izin tulis ke repo baru hanya karena owner dan repo diubah.
Repo geleri berstatus publik pada saat unggahan; foto dapat diakses publik melalui GitHub. Token tidak membuat repo publik menjadi privat.
